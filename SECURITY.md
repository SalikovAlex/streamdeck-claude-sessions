# Security

Use GitHub's [private vulnerability reporting](https://github.com/SalikovAlex/streamdeck-claude-sessions/security/advisories/new) for suspected security issues. Include the affected version, reproduction steps, and impact. Do not post credentials or private session data in public issues.

Security fixes target the latest release. This is a community project with no guaranteed response time.

The plugin reads local process and session metadata and uses macOS Automation to focus CLI sessions. Codex databases are opened read-only. See [README.md](README.md#privacy-and-support) for local data and logging details.
